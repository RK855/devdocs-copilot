# NumPy 数组基础

## ndarray

NumPy 的核心是 `ndarray`，同类型元素的多维数组。相比 Python 列表，内存连续、运算向量化，速度快一个数量级。

```python
import numpy as np

a = np.array([[1, 2, 3], [4, 5, 6]])
print(a.shape, a.dtype)
```

`shape` 描述维度，`dtype` 描述元素类型。默认整型为 int64，浮点为 float64。显式指定 dtype 可以节省内存。

## 创建数组

`np.zeros`、`np.ones`、`np.full` 创建填充数组，`np.arange` 按步长生成，`np.linspace` 按数量等分，`np.random` 生成随机数。`np.eye` 生成单位矩阵。

## 索引与切片

切片返回视图而非副本，修改视图会影响原数组。需要独立副本用 `.copy()`。布尔索引返回副本。

```python
a[a > 3]        # 布尔索引
a[:, 1]         # 第二列
a[0, :2]        # 第一行前两列
```

## 广播

广播让不同形状的数组参与运算。规则是从尾部维度对齐，维度长度为 1 或缺失时可扩展。例如 `(3,1)` 与 `(1,4)` 得到 `(3,4)`。广播不复制数据，节省内存，但形状不兼容时会报错。

## 常用运算

`sum`、`mean`、`std`、`min`、`max` 支持 `axis` 参数按维度聚合。`np.dot` 或 `@` 做矩阵乘法。`reshape` 改变形状，`transpose` 转置，`concatenate` 拼接，`stack` 堆叠。

## 向量化与性能

避免 Python 循环逐元素运算，改用向量化表达式。向量化在 C 层执行，快得多。确实需要循环时，优先用 `np.vectorize`（本质仍是循环，仅改善写法）或 `numba` 加速。

## 内存布局

默认 C 顺序（行优先），`order="F"` 为列优先。转置返回视图但改变步长，后续运算可能变慢。大数组运算注意临时副本的内存峰值。

## 与列表转换

`np.array(list)` 复制数据，`tolist()` 转回列表。混合类型列表会退化成 object dtype，失去向量化优势。

## 常见坑

- 切片得到视图却当成副本修改
- 整数除法与浮点精度问题
- 广播方向搞错导致形状错误
- 用循环代替向量化
- 大数组一次性加载导致内存溢出
