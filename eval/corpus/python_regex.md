# 正则表达式基础

## 常用元字符

`.` 匹配任意字符（默认不含换行），`*` 零次或多次，`+` 一次或多次，`?` 零次或一次，`{m,n}` 指定次数范围。`^` 行首，`$` 行尾，`\b` 词边界。

字符集 `[abc]` 匹配其中之一，`[^abc]` 排除。范围 `[a-z]`、`[0-9]`。预定义类 `\d` 数字、`\w` 单词字符、`\s` 空白。

## 分组与捕获

`(...)` 是捕获组，`(?:...)` 是非捕获组。捕获组可以提取子串，也在替换中用 `\1` 或 `$1` 引用。命名组 `(?P<name>...)` 在 Python 中可通过 `groupdict()` 获取，可读性更好。

```python
m = re.match(r"(?P<year>\d{4})-(?P<month>\d{2})", "2026-09")
print(m.group("year"), m.group("month"))
```

## 贪婪与非贪婪

`*` 与 `+` 默认贪婪，尽量多匹配；加 `?` 变非贪婪，尽量少匹配。`<.*>` 会匹配到最后一个 `>`，`<.*?>` 只匹配到第一个。处理 HTML 时不要用正则，改用解析器。

## 常用函数

`re.match` 从开头匹配，`re.search` 扫描任意位置，`re.fullmatch` 要求整串匹配，`re.findall` 返回所有匹配，`re.sub` 替换。`re.compile` 预编译模式，重复使用时更快。

## 替换与回调

`re.sub(pattern, repl, text)` 的 repl 可以是字符串或函数。函数接收 match 对象，返回替换内容，适合动态处理。

```python
re.sub(r"\d+", lambda m: str(int(m.group()) * 2), "a1 b2")
```

## 边界与转义

特殊字符要转义，例如匹配点号用 `\.`。原始字符串 `r"\d+"` 避免反斜杠被 Python 转义。Windows 路径含反斜杠，写正则时尤其要小心。

## 中文与 Unicode

Python 3 的 `\w` 默认匹配 Unicode 字母，包括中文。需要只匹配 ASCII 时加 `re.ASCII` 标志。处理中文分词时正则常用来切分标点与英文代码词。

## 性能

灾难性回溯是正则的经典陷阱：嵌套量词如 `(a+)+$` 在长字符串上指数级爆炸。避免嵌套量词，尽量具体化字符集，限制长度。对不可信输入要设置超时或改用解析器。

## 常见坑

- 用正则解析 HTML/JSON
- 贪婪匹配吞掉过多内容
- 忘记锚点导致部分匹配
- 复杂正则无注释难维护
- 对超长输入使用易回溯的模式
