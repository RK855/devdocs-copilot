# DevDocs Copilot 使用文档（面向使用者）

> 本文档面向**最终使用者**：怎么启动、怎么提问、怎么上传自己的文档、数据保存在哪里。
> 如果你想了解技术架构、模块划分、接口设计，请看同一知识库中的《项目说明文档》；
> 看不懂 RAG、Embedding、精排这些词，随时查《AI 术语手册》。

---

## 1. 这个软件能做什么

DevDocs Copilot 是一个**本地运行的技术文档问答助手**。你把自己的文档（Markdown、
TXT、PDF、Word）传进去，它会基于这些文档回答你的问题，而不是凭空编造：

- 回答只基于知识库中**真实检索到的内容**，并附上来源文档；
- 知识库里没有依据时，它会明确告诉你"查不到"，而不是硬答；
- 除浏览器界面外不需要安装任何其他东西（桌面绿色版已内置 Python 运行时）。

它有两种问答模式：

| 模式 | 适合什么问题 | 工作方式 |
| --- | --- | --- |
| **RAG**（默认） | 答案明确、一次检索就能找到的问题，如"FastAPI 怎么做请求体校验" | 检索一轮相关文档，直接组织答案，速度快 |
| **AGENT** | 需要多步排查的复杂问题，如"帮我分析这个 500 报错可能涉及哪些环节" | 模型自主决定调用哪些工具（文档检索 / 代码示例生成 / 报错解释），多轮循环，并实时展示执行轨迹 |

模式切换在页面顶部的 **RAG / AGENT** 分段开关，切换后下一次提问立即生效。

## 2. 第一次怎么启动

1. 双击程序目录里的 **DevDocsCopilot.exe**，会出现一个黑色控制台窗口（**不要关**，
   它就是服务本体，关窗等于退出程序）；
2. 第一次启动会要求填写两个 API Key，窗口里有详细的免费申请指引，按提示操作即可；
3. Key 填好并重新启动后，程序会把随包预置文档灌入知识库（仅第一次需要，需联网，
   文档越多耗时越长，请耐心等待窗口提示完成）；
4. 灌库完成后浏览器会自动打开问答页面（默认地址 `http://127.0.0.1:8000`）。
   如果浏览器没自动打开，手动在浏览器地址栏输入该地址即可；
5. 以后每次双击启动都是秒开，配置和知识库都会保留。

端口 8000 被占用时程序会自动顺延寻找空闲端口，实际地址以控制台窗口中
"服务地址"一行为准。服务只监听本机（127.0.0.1），局域网其他设备访问不到。

## 3. 怎么提问

- 在底部输入框输入问题（最长 2000 字），点发送按钮或按回车；
- 回答是**流式输出**的，会一个字一个字地出现。生成过程中发送键会变成红色的
  **「停止」**，点它可以中途打断；打断后已生成的文字会保留，旁边出现重试按钮；
- 回答渲染完成后，下方会显示 **来源卡片**：答案引用了哪些文档、来自第几页（PDF），
  点击可以展开核对原文。养成看来源的习惯——它能帮你判断答案是否可信；
- 如果检索不到足够相关的内容，系统会返回拒答文案。拒答不是故障，而是它在
  诚实地告诉你"知识库里没有依据"；
- 在 **AGENT 模式**下被拒答时，回答区会出现 **「🧠 用通用知识再答」** 按钮。
  点击后会允许模型用自身的通用知识回答一次，回答顶部会带琥珀色的
  "GENERAL · 通用知识作答"标记和免责声明——这类内容**不来自你的知识库**，
  需要自行核实。该授权只对当次提问有效。

提问小贴士：问题越具体，检索越准。优先问"怎么做 / 为什么 / 在哪里配置"这类
能在文档里找到原文依据的问题；代码标识符、报错信息尽量原样粘贴，分词检索
（BM25）对精确符号很敏感。

## 4. 上传与管理自己的文档

### 4.1 上传

- 点左侧上传区选择文件，支持 **.md / .txt / .pdf / .docx**，单个文件不超过 **10MB**；
- 上传后程序自动完成解析、切分、向量化，文档立刻可被检索，无需重启；
- PDF 请使用带文字层的电子文档，**扫描件/图片版 PDF 提取不到文字**，无法入库。

### 4.2 "语料库"和"我的上传"两个视图

左侧栏顶部有两个分段：

- **语料库**：本次启动服务时已在知识库里的全部文档（含预置文档和更早之前上传的）；
- **我的上传**：**本次启动之后**你新上传的文档，按钮上的数字是实时计数。

注意这只是**视图分组**：重启服务后，上次上传的文档会自动"沉淀"进语料库，
但它们一直在知识库里，任何时候都参与检索，一条都不会丢。

### 4.3 删除文档

在文档列表里可以删除文档。删除会同时清掉三样东西：向量库里的向量、BM25 关键词
索引、`uploads` 目录里的源文件。删除不可恢复，需要时重新上传即可。

## 5. 限定在部分文档里检索（检索范围）

默认是**全库检索**。想只查某几篇文档时：

1. 点输入框左下角的 **「选文档」** 按钮，在弹层里勾选 1 到多篇文档（按
   语料库 / 我的上传分组），点确定；勾选 0 篇等于恢复全库；
2. 设定范围后，输入框上方会出现金色**范围条**，显示当前限定在哪些文档，
   每个文档可以单独摘除，也可以点 **「结束本次检索」** 一键恢复全库；
3. 范围内的文档在左栏会有金色高亮；回答后范围条会闪烁提醒当前仍是限定状态；
4. 切换"语料库 / 我的上传"视图会放弃显式勾选，范围跟随当前视图；
   RAG / Agent 模式切换时范围保留；中断后点"重试"也会复用当轮范围；
5. 如果当前视图是空的（比如"我的上传"里还没有文档），发送会被前端拦截，
   避免发出注定无结果的提问。

## 6. 数据保存在哪里 · 隐私 · 卸载

桌面绿色版所有运行时数据都在 **DevDocsCopilot.exe 所在的文件夹**里：

| 路径 | 内容 |
| --- | --- |
| `.env` | 你的两个 API Key（纯文本保存在本机，不随分发包分发） |
| `data/` | Chroma 向量数据库（所有文档的向量与切分文本） |
| `uploads/` | 上传文档的原始文件（含预置文档的副本） |

不写注册表、不往系统目录散落文件。**卸载就是关闭程序后删掉整个文件夹**；
想备份知识库，复制 `data` 和 `uploads` 两个目录即可。

隐私边界要心里有数：文档原文不出本机，但——

- 文档切分后的文本会发送到**硅基流动**的接口生成向量（Embedding）；
- 你的问题和检索到的文档片段会发送到 **Agnes** 的接口生成回答。

因此不要上传法律法规或公司制度禁止出网的机密资料；如需用于敏感场景，
应改为对接企业自有的、部署在内网的模型服务。

## 7. 常见问题

**Q：启动时提示 Key 有问题 / 回答时报认证错误？**
A：检查 `.env` 里两个 Key 是否复制完整、等号两边没有空格、没有加引号；
聊天模型与向量模型是两个不同平台，Key 不能混用。改完保存后重启程序。

**Q：预置文档灌库失败了？**
A：常见原因是 Key 填错或网络不通。控制台会询问是否仍然启动；退出后修正
问题再重新双击，程序检测到库为空会自动重新灌库。

**Q：问什么都被拒答？**
A：先确认知识库里确实有相关文档（左栏能看到）；再换用文档里的原词原样提问。
如果是 Agent 模式，可以观察它的检索轨迹里查询词和命中条数，判断是问题
太宽泛还是文档本身没覆盖。

**Q：回答到一半停了？**
A：网络抖动或模型服务超时会导致流中断，已生成的文本保留，点重试即可；
连续失败请稍后再试或检查网络。

**Q：换了一个向量模型后启动异常 / 检索全乱？**
A：向量维度与建库时不一致会导致检索失效。换 Embedding 模型必须同步修改
`.env` 里的 `EMBEDDING_DIM`，然后**删除 `data` 目录重启**，让知识库以新维度
重建（预置文档会重新灌入，自行上传的文档需重新上传）。

**Q：端口打不开 / 地址是多少？**
A：以黑色控制台窗口打印的"服务地址"为准；确认窗口没有被关闭、杀毒软件
没有拦截本机端口监听。

## 8. 给想深入了解的人

同一知识库里还预置了两份文档：

- 《项目说明文档》：项目概述、技术选型、系统架构、数据流转、模块与 API 设计、
  评测方案、部署规划——想了解"它是怎么造出来的"看这份；
- 《AI 术语手册》：RAG、Embedding、混合检索、RRF、精排、ReAct、证据门等
  术语的通俗解释——看说明文档时被名词卡住就查这份。

你也完全可以把这三份文档删掉、换成自己团队的文档，它们就是普通的知识库内容，
不参与程序运行逻辑。
